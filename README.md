**RESTAURANT ANALYTICS PROJECT**

This project analyses restaurant performance, customer orders, revenue, ratings, cuisines, and location-wise trends. The objective is to identify high-performing restaurants, understand factors associated with restaurant success, evaluate online ordering performance, and recommend suitable locations for business expansion.

Data Source: Restaurant Analytics Case Study – Five datasets: Restaurants, Orders, Customers, Locations, and Cuisines.

Tools & Technologies: Python, Pandas, NumPy, Matplotlib, Seaborn, Excel, SQL, Power BI, DAX, Jupyter Notebook.

Steps Performed:

Data Pre-processing: Handled missing values, removed duplicates, corrected inconsistent text values, converted data types, and handled invalid numerical values.

Exploratory Data Analysis (EDA): Analysed restaurant ratings, average cost, customer orders, revenue, cancellations, and cuisine preferences.

Data Analysis: Merged datasets and performed group-by analysis to compare restaurant performance across locations, cuisines, and order categories.

Data Visualization: Created charts to analyse restaurant counts by location, average ratings, rating distribution, ratings versus votes, monthly revenue trends, and online ordering performance.

Dashboard Development: Developed interactive Power BI dashboards using KPI cards, charts, tables, slicers, and DAX measures to monitor restaurant and business performance.

This project demonstrates how data analytics can support data-driven decision-making in the restaurant industry. The analysis helps identify potential expansion locations, understand restaurant performance, evaluate online ordering, and recommend strategies to improve revenue and customer experience.
